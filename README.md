# FitLog 

## About This Project
FitLog is a simple and easy-to-use fitness web application. It allows you to browse a library of exercises, read detailed workout instructions, and build a custom daily workout plan to hit your fitness goals.

## Technologies Used
* **Next.js (App Router)** - For building the website and handling page routing.
* **React & TypeScript** - For building interactive UI components with safe, error-free code.
* **Tailwind CSS** - For quick, responsive, and custom styling.
* **DaisyUI** - For beautiful pre-built components (buttons, skeletons, dropdowns) and themes.
* **Local Storage** - To securely save your workout plans directly in your browser without needing a database.

## 5 Key Features
1. **Workout Library:** Browse a grid of different exercises covering every major muscle group.
2. **Detailed Instructions:** Click on any workout to see exactly how to perform it, what equipment is needed, and how hard it is.
3. **Build Your Plan:** Add exercises to "Today's Plan" or "Save" them for a future workout.
4. **Track Daily Stats:** Automatically calculate the total workout time and total calories burned for your daily plan.
5. **Sort & Organize:** Easily sort your planned or saved workouts by duration, calories burned, or rating on the "My Plan" page.
